# PET PET LAND 宠之岛

Open `index.html` in a browser to view the local static page, or publish this repository with GitHub Pages.

This version rethemes the original visual study into PET PET LAND / 宠之岛: a Nanjing Jiangbei New Area place where owners and pets can play, socialize, and watch movies together.

## Files

- `index.html` - page markup
- `styles.css` - layout, responsive styles, and visual system
- `script.js` - preloader, activity slider, MP3 music toggle, step controls, map controls
- `three-snack.js` - Three.js scene setup for the pet/social/cinema stages
- `assets/` - shipped SVGs, GLB models, local Three.js vendor files, and local audio

## GitHub Pages

Recommended Pages setting:

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/root`
